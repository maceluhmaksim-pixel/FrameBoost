# FrameBoost — форма зворотного зв'язку (ЛР №9)

Адаптивна форма зворотного зв'язку з клієнтською валідацією, вбудована в лендинг **FrameBoost** (калькулятор bottleneck для ПК).
Стек: HTML5 + Tailwind CSS (CDN) + Vanilla JavaScript. Без сторонніх бібліотек для валідації.

> **Важливо.** Реального надсилання даних немає: бекенд не підключено. Скрипт перехоплює `submit`
> (`preventDefault()`), перевіряє поля, показує модальне вікно «Імітація успішного надсилання» і очищає форму.

## Правила валідації

| Поле | Тип | Правило | RegEx / умова |
|---|---|---|---|
| Ім'я | text | обов'язкове, ≥ 2 символи (після trim) | `[...value.trim()].length >= 2` |
| Емейл | email | коректний формат | `/^[A-Za-z0-9._%+-]+@[A-Za-z0-9-]+(?:\.[A-Za-z0-9-]+)*\.[A-Za-z]{2,}$/` |
| Телефон | tel | строго `+380` + 9 цифр | `/^\+380\d{9}$/` |
| Повідомлення | textarea | ≥ 10 символів (після trim), максимум 1000 | `[...value.trim()].length >= 10` |
| Згода | checkbox | обов'язково checked | `checked === true` |
| Тема | select | необов'язкова | — |

## Поведінка

- Після відкриття сторінки помилок немає.
- Під час набору червона помилка не з'являється, доки поле не втратило фокус (`blur`). Валідне значення позначається зеленим одразу.
- Після першого `blur` поле перевіряється в реальному часі (`input`).
- `submit` перевіряє всі поля, ставить фокус на перше невалідне і показує підсумок.
- Для телефону в форматах `0501234567`, `+380 50 123 45 67`, `380501234567` показується кнопка «Замінити на +380…». Значення автоматично не змінюється.
- Подвійний швидкий submit не відкриває модальне вікно двічі.

## Доступність

`label[for]` ↔ `input[id]`, `name` у кожного поля, `aria-describedby` (підказка + помилка), `aria-invalid="true|false"`,
`aria-live="polite"` для помилок, `:focus-visible`, елементи керування від 44 px, модальне вікно на нативному `<dialog>`
(фокус-пастка, Esc, повернення фокуса).

## Запуск локально

Збірка не потрібна: відкрийте `index.html` у браузері або запустіть, наприклад, `python -m http.server 8000`
і перейдіть на `http://localhost:8000`.

## Відомі обмеження

- Клієнтську валідацію можна обійти. Для реального бекенду правила потрібно дублювати на сервері.
- Email RegEx спрощений (ASCII): кириличні адреси та IDN не проходять.
- Tailwind підключено через Play CDN (як у попередніх ЛР). Для продакшну краще зібрати CSS через Tailwind CLI.
